# 🐾 Sistema de Proteção e Bem-Estar Animal - Bauru

Sistema completo para gerenciamento e proteção do bem-estar animal na região de Bauru.

## 📋 Descrição

Este projeto foi desenvolvido com o objetivo de criar uma plataforma robusta e escalável para:
- Registrar e monitorar animais em situação de risco
- Gerenciar denúncias de maus-tratos
- Coordenar ações de proteção animal
- Facilitar a comunicação entre protetores e autoridades

## 🚀 Início Rápido

### Pré-requisitos
- Node.js 18.0.0 ou superior
- npm ou yarn

### Instalação

```bash
# Clonar o repositório
git clone https://github.com/mexfar-sys/protecao-animal-bauru.git
cd protecao-animal-bauru

# Instalar dependências
npm install
```

### Desenvolvimento

```bash
# Compilar TypeScript
npm run build

# Executar em modo desenvolvimento
npm run dev

# Iniciar aplicação compilada
npm start
```

### Testes

```bash
# Executar testes
npm run test

# Verificar linting
npm run lint
```
